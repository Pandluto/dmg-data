# 排轴局部接续放大镜任务

对应 [Accepted Spec](spec.md)。**Implementation: First iteration implemented; verification partial**。下列复选项只在实现与对应证据核对后勾选；用户授权方向不等于验收通过。更新于 2026-09-06。

## 当前核对状态

- 镜面渲染器已经接入主工作台，原 Chrome 已打开，真实拖动、快捷键、边界与提交次数仍在逐项验证；不能因此勾选全部 Chrome 验收。
- provider 已发送此前遗漏的起止关系，小队 runner 按实际起止、命中和切人事件解析。显式依赖采用指定时刻准入；未到达的来源不释放后继。固定命中偏移、结束后切人/下落、完整普攻结束及窗口边界已有对应回归证据；任务仍需与 UI 链路一并闭合。
- 已核对卡缪 Q 的 `AllowNext` 提前衔接与实际结束是不同事件：恢复保存的 action-end 关系会改变运行时输入图，不能把前后帧差解释为局部放大造成的结果漂移，也不代表新的排列更优。
- timed-input v1 已按来源实际起点加保存偏移再核验真实窗口；来源内部窗口变动导致原落点失效时拒绝，不自动重定位。旧关系缺少窗口元信息时继续只表达原起点偏移。
- 当前无关系同帧排序、等待来源运行时事件、单角色 runner 依赖 API 和新 `AllowNext` 接点均保留 Spec 中的范围边界。
- 运行时与 Chrome 证据已归档到 [本轮验证记录](../../maintenance/evidence/release-lens-20260906/verification.md) 及同目录 JSON。
