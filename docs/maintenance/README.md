## 提交追溯

- [基线提交演变](./development-history.md)逐条记录初始提交至 `0bea9f8`。
- 此后提交以仓库 `git log` 为完整事实源；维护记录解释原因，不复制 Git 的文件级差异。
- 历史正文只从 [档案入口](../archive/README.md)恢复，不参与当前验收。

## 写入规则

跨版本数据升级、文档迁移、破坏性架构转换、需要明确恢复点的工作可以新增维护记录。引擎实验与优化建议优先更新现有探索索引，链接独立证据，避免每次排列都生成新文档。普通实现细节留在提交和测试中；已接受且会持续约束未来实现的架构选择写入 [ADR](../architecture/decisions/README.md)。
