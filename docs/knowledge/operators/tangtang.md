2026-09-05 后续配装实验更正：此前“同根 child cast 各施一次寒冷”的解释被真实 B@0、C@60、B@120 推翻。第二次 B 的三条龙卷原错误地在 F143 连续施冷三次；按同一次技能施放限次后只施冷一次，龙卷伤害仍保留。不同 B@0/150/300 仍在 F23/173/323 分别施冷。这是修正旧结论，不是技能数据发生变化。

限次证明范围是原始标记有效期内。标记 `buff_chr_0027_tangtang_comboskill_spelllnfliction` 使用 6 秒全局寿命；仅别礼终结技的暂停就能把旧龙卷拉长到标记过期后，同根实体可能再次施冷，不要求多个终结技。该时钟组合仍待独立核验，不能用永久 cast 缓存替代原始寿命，也不能把该额外施冷计入已验证最优结论。

后续完整配装还发现了法术脆弱漏算：父 Buff 的 `SaveBuffLifeTime(Environment)` 应把剩余寿命存入 `real_duration`；此前未编译此动作，易伤以 0 秒创建并立即结束。补齐实例计时器读取后，实际易伤从 F126 持续到 F576。其字符串子 Buff ID 另因 Blackboard 的默认数字槽遮盖字符串槽而被读成 0；子 Buff 负责显示，易伤倍率的真正漏算来自寿命链，两者不可混为一因。

## 下落输入与跨角色触发

区分普通战技水龙卷与终结技提前结束派生的额外龙卷：前者不要求下落；后者由领域内主控的下落命中触发，不能把所有水龙卷统一加上下落门槛。

显式输入为 `Attack + attackMode: plunging-impact`，代表落地动作开始时刻；执行该角色原始 `CharacterPlungingAttack` 结尾程序，保留实际命中偏移。别礼偏移为 +2 帧，汤汤为 +3/+5/+7/+9 帧。落地时刻被动作占用就拒绝，不排队到未来；普通 A 仍执行普通连段。已为原始数据中的 32 名角色生成落地能力，具体交互验收只覆盖下列场景。

真实链路为：主控落地的 `OnBeforeDamageAction` → 领域 Aura 校验 `Attack/-4` 与伤害装饰掩码 `1024` → 主控标记 → 领域 `OnOutputBuff` 监听 → 跳至提前结束分支。Q 自然结束的 FinishOwner 阻止其继续进入提前结束分支；禁用的 `OnOutputDamage` 分支不能作为依据。

在 Q@0 / 别礼落地@100 的对照中，F102 触发一次跳转，F107 出现 7 倍巨浪及后续十二跳龙卷。普通攻击、非主控落地、领域时窗外落地均不能无条件获得强化。跨角色触发后，`rootCastId` / `damageSourceId` 仍属于汤汤 Q；独立 `triggerCastId`、`triggerRootCastId`、`triggerSourceId`、`triggerSkillId`、`triggerFrame` 记录别礼落地。没有事务证据时字段为空，禁止用“碰巧同帧”推断。

Chrome 完整配装案例 `run-2770cd23-ede6-4639-9a42-3dcd23bfaa0c` / `browser-case-20260905T130421155z-d958b904`：汤汤 Q@222、别礼落地@352、别礼 Q@361。F354 落地触发，F359 强化巨浪，F459—547 十二跳新龙卷；F459 的新冰属于汤汤 Q 的新根施放，不能混同于 F206 已消费的四层冰或旧龙卷跨时钟重施。总伤害 707607.4016083797，实际尾伤结束 F547，技力 86.40；F548 再请求战技因资源不足被拒绝。这是有限候选中的已验证方案，不是全局最优证明。

主轴以真实触发帧展示交互，可点击查看触发动作和派生伤害；寒冷变化记在实际施加者一行，关联触发另存，避免将汤汤附着错误归给别礼。
