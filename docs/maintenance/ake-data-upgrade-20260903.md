## 升级暴露的问题与裁决

1. 新角色引用 88 个资产索引外 JSON。裁决：递归依赖闭包成为同步和验收的一等产物，不能只信索引前缀扫描。
2. 当前上游仍缺少 5 个被真实引用的文件。裁决：保持显式 missing，禁止生成空定义；具体路径由证据页自动列出。
3. 升级当时，提弗洛斯触发尚未支持的 `TimedGrowingEnhance` 状态叠层策略。裁决：当时的 timing 画像保留 diagnostic 并降级为静态结构 fallback，不能宣称角色运行闭合。
4. 升级当时，静态 fallback 对同一子技能图进行逐路径展开时产生数十万重复 Hit，导致 V8 无法序列化。裁决：按 `frame + source skill` 聚合结构命中，只保留一个代表结构命中，不把重复图路径冒充已证明的运行时命中次数；该输出当时仍因 diagnostic 不具备行为精度。
5. 旧来源锁只逐项登记少量表和佩丽卡文件，不能证明全语料一致。裁决：锁 schema 升级，加入表/运行时 manifest 哈希、内容哈希、索引 revision 和闭包摘要。
6. 参考分析生成器会把完整运行时语料全部展开，而该目录原本只是来源锁样本的第三方展示视图。裁决：默认选择来源锁中的样本，生成器清理自身越界输出，一致性门同时验证输入集合、分析器、输出哈希和 manifest。
