## 默认配装

- 六星干员零潜，五星干员满潜。
- 六星武器零潜，五星武器满潜；为干员装备适配武器。
- 装备通常装齐四个槽位，配装、技能等级、武器等级与强化档位在实验输入中明确保留。

这是一般开发实验的起点，具体任务中用户指定的条件优先。为了隔离单一机制而临时简化配装时，应说明改动及证明范围；回到实战排轴比较时恢复完整配装。

潜能与等级、技能培养、武器词条/基质强化是不同维度。零潜不等于角色一级或武器词条一级；实际输入应通过前端 provider 核对有效参数，不能仅看星形计数器的内部数字。

## 与热启动和最终界面的关系

需要热启动时按 [热启动条目](../terms/hot-start.md) 给全员各自满终结技能量，其他资源单独固定。实验结果要能落回用户正在使用的 Chrome 配装和排轴界面；用户要求保留最佳方案时，最终停留在该方案并核对实际保存内容。
