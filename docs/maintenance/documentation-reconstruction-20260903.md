## 与参考风格的关系

本次保留 DEF 的核心风格：短索引、稳定 `spec.md`、architecture 只写当前事实、ADR 只记持续约束、maintenance 保存迁移和恢复方式。Spec 结构采用 Matt Pocock `to-spec` 的完整用户故事和实现/测试决策模板。

没有照搬 DEF 的产品合同或目录内容；本项目额外需要 generated evidence 与来源语料哈希，因为 clean-room 正确性依赖外部数据版本和审计结果。

## 正确性门

基础验收依次检查：

1. 来源锁、表语料、索引语料和递归闭包一致；
2. 当前证据页可以由当前输入字节重建；
3. 文档入口、相对链接、Spec 结构和目录纪律成立；
4. 根引擎与冻结 oracle 回归通过。

前端、Demo、RIA 和真实浏览器继续按改动范围追加，不被基础门的成功替代。
