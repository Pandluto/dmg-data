# 排轴阅读与批量模式 Spec

## Status

**Status:** Accepted for implementation

**Implementation:** Implemented and integrated; Chrome reading/toggle checks passed, native batch gesture acceptance pending

**Updated:** 2026-09-06

**Baseline:** 7ac9753（2026-09-06）；本规格提交为包含本文件的提交。

**Scope:** 桌面 Web；沿用现有书本浏览入口，新增批量框选入口。

## Problem Statement

当前浏览模式未适配 AKE 的动作时长、命中、拖尾和状态投影，读组合仍被编辑细节干扰。现有删除只允许合法队尾，批量清理需要重复操作；旧右键复制不适用于当前队列语义。

## Solution / 设计稿

工具栏顺序保留既有入口，在书本旁增加虚线框选 SVG。书本的可访问名称统一为「阅读模式」，不改眼睛「查看」入口的功能。

阅读模式中，每个技能是一张独立白底卡片：1px 黑色细框、6px 圆角。宽度沿用现有 80px 操作占位，卡片垂直范围只包住技能与状态，不覆盖起手、能量行；建议上下内边距 5px，横向 4px，以实际内容不相撞为准。

```text
普通模式：起手关系 / 技能 / 时间 / 命中 / 拖尾 / 状态

阅读模式：
别礼  ╭────────────────╮    ╭────────────────╮
      │ 技能图标 战技  ❄₁ │    │ 技能图标 连携  ❄× │
      ╰────────────────╯    ╰────────────────╯
汤汤  ╭────────────────╮
      │ 技能图标 战技  ❄₂ │
      ╰────────────────╯

批量模式：针形光标拖出选框 → 高亮所选 → 右键「删除所选 N 项」
```

示意只说明归属，不代表固定像素文字宽度。状态沿用现有 20px、原元素色、双黑框窄白环、大白图案带阴影、黑粗体层数。附着与破防位于对应来源技能卡片内，不挂在整组右上角。

## User Stories

1. 用户点书本即可只读组合顺序、技能类型与状态结果，再点一次恢复原编辑信息。
2. 用户框选多个队尾动作，右键一次删除；框入中间动作时能明确知道为什么不能删。

## Requirements

### Requirement READ-01: 只显示组合关键信息

- WHEN 开启书本阅读模式
- THEN 保留角色、分组、操作顺序、技能图标和类型、来源技能对应的附着/破防层数，以及必要的等待/切人简短标识
- AND 隐藏时长文字、时间刻线、命中点和说明、动作区间条、拖尾条、伤害数、可释放菱形、起手接续时间和状态引线；保留共享技力条、每个角色的能量条与分组框/边界，角色身份保留
- AND 每个技能及其状态处于同一白色圆角细黑框内；状态不可被不透明卡片遮挡
- AND 同一来源同一状态跨帧多次变化时，卡片只显示该来源最后一条结果，归零显示 ×；不把别的来源的状态合并进来。详情保留全部原始事务
- AND 不改变任何帧、按钮 ID、依赖、伤害、资源或存档，不新增模拟计算；再次关闭恢复原视图
- AND 阅读模式禁止新增/拖拽/删除；单击可查看状态详情，不能因事件冒泡执行编辑动作

### Requirement BATCH-01: 明确的框选模式

- WHEN 点击新增批量 SVG
- THEN 退出阅读模式，按钮显示选中状态，画布变为针形光标（准确 hotspot，失败回退 crosshair）；工具栏正常光标
- AND 从画布拖拽框选，按可见技能按钮中心进入选框判定选中，跨角色/页可选；仅状态角标不构成新操作
- AND 选框使用轻浅填充、细边线，选中卡片清楚高亮；拖动只更新选择，不搬动已有技能，不打开接续放大镜
- AND 普通框选替换选择，空白点击清空；Escape 或再点批量入口退出并清空，pointercancel 清除临时选框
- AND 打开阅读模式时退出批量模式；存档/队伍切换后清空选择，避免旧 ID 残留

### Requirement BATCH-02: 只删除合法队尾集合

- WHEN 有选择且右键
- THEN 显示「删除所选 N 项」；不提供失效的复制项
- AND 在当前最新队列副本上，反复使用现有 getTimelineDeleteBlockReason 找出可合法删除的选中尾项并模拟移除；全部选择都可移除才允许执行
- AND 不能用最大 x、最大 frame 或数组最后一项替代合法性规则；必须处理跨角色、同帧、分组、显式依赖及普攻拆段尾链
- AND 任一中间项或未选后继阻塞时整批不删，显示具体原因；不自动多删未选动作
- AND 执行前再次核验最新状态；同一事务应用全部移除、形成一次撤销记录并触发一次重算，禁止逐个触发计算或留下半删状态
- AND 复用原单项删除对关联数据的清理语义；不改变默认模式的队尾限制

## Implementation Decisions

- 阅读入口：SkillSandbox.tsx 的 isBrowseMode / onToggleBrowseMode；显示接入 CanvasArea、SkillButton 与 TimelineStateMarkers，样式须限定阅读模式。
- 批量入口同在 SkillSandbox；CanvasBoard/index.tsx 负责模式协调和原子编辑；选择几何和删除预检优先抽独立 hook/domain helper，避免继续膨胀主组件。
- 原单项删除：CanvasBoard/index.tsx 的 handleConfirmRemoveSkillButton、core/domain/timelineQueuePolicy.ts；先理解拆段关联删除。
- DEF 只读参考：/Users/sailstellar/Documents/coding/dmg-end-field/src/components/BuffBatchEditWorkbench.tsx 的 isBoxSelectArmed 及其 hook；不恢复旧 buff 填充功能，不继承参考库的发布约定。
- 两项实现各自独立 checkout 和提交。共享入口由主代理合并，最终协调为单一模式状态，不能互相覆盖。

## Testing Decisions

阅读模式用固定真实轴核对隐藏内容、卡片归属、退出恢复与输入不变；不写镜像 CSS 测试。批量删除保留合法队尾、混入中间项、跨角色依赖、同帧与撤销原子性回归。运行受影响的定向检查和 typecheck，不运行无关全套。主代理拥有当前 Chrome，实施任务不得切换或改写该页面。

## Out of Scope

手机版、buff 填充、复制粘贴、中间删除/移动、重新设计时间投影、推送与部署。

## Further Notes

本设计依据用户 2026-09-06 的两条并行要求。阅读模式是组合摘要，详细生效顺序仍在编辑视图与状态详情中；不将摘要伪装成某个全局时刻的状态快照。实现任务完成后由主代理合并、用 Chrome/RIA 复核，并回填验收状态。
