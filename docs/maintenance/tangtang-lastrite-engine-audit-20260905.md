# 汤汤、别礼：通用引擎审计（2026-09-05）

本轮使用仓库内原始 AKE SkillData / BuffData / SkillPatchTable，并通过真实双人队伍运行、单变量实验和可见 Google Chrome 的 RIA 接口验证。角色名称只出现在数据映射与实验输入中；公共执行逻辑不按这两个角色 ID 分支。

后续更正（2026-09-05 配装实验）：下文关于“同根水龙卷 child cast 各施冷”的旧解释已被真实 B→C→B 反例推翻。技能描述要求同次战技多个水龙卷不能重复施冷，修正后的知识与边界见 [汤汤条目](../knowledge/operators/tangtang.md)。本页保留首次审计经过，不能继续用旧解释判断合法排轴。

## 已确认的根因与修复

| 问题 | 原表现 | 修复与证据 |
| --- | --- | --- |
| 初始主控和换人没有贯通 | 每次施法者被当成主控，后台别礼也能触发只属于主控的灌注 | UI 输入、API、两种 runner 与运行时共享主控状态；延迟命中和 MainCharacter 目标引用读取发生当时的主控。切人事件保留时间、顺序与释放依赖。 |
| 连携触发门槛未接通 | 没有寒冷、没有爆发时，两人也能直接施放连携 | 补齐公开描述对应的三个声明规则和状态前后层数、法术爆发事件。空场拒绝；一、二层寒冷只开汤汤，二到三层开别礼，三到四层不伪造再次跨阈值；真实同元素火爆发也能开汤汤，友方寒冷不能开。 |
| 限次状态没有按施法隔离 | B@0/150/300 的寒冷迟到 F23/205/387，旧技能标记挡住新技能 | 保留原始 `limitSkillCastId`，在目标、Buff/tag 过滤后按当前 cast 计数；施冷恢复 F23/173/323，别礼 C@350 合法并消费三层。同根施法下两个独立水龙卷 child cast 也分别施冷。 |
| 施法替代语义丢失 | 别礼普攻中插入战技，原普攻后半段或重击消失 | 原始 `switchToBuffConfig.asSkillCast=true` 条件满足时转为瞬时 Buff 施放，单独付费和冷却，保留原前台动作。真实普攻 F12/30/44/58/76/106 六击在战技 F50 或 F95 插入后完全保留，并产生 F115 追击。 |
| 前端不接受瞬时动作 | 引擎已正确施放，预览却仍占普通战技时长，关系轴拒绝零时长 | 预览消费同一施法替代条件，显式标识 instantaneous；合法零时长动作保留可视列但不占战斗时长、不截断普攻。真实 HTTP catalog 的 A＋B@45＋B@77 预览两轮收敛，无关系问题，普攻仍结束于 F131。 |
| 聚合普攻的命中锚点使用了错误时钟 | Chrome 中 B 锚定整段普攻 F44 后，预览为 F45，实际报 `RELEASE_ANCHOR_NOT_REACHED` | 整按钮偏移与源 SkillData 的 timelineFrame 分开保留。该命中属于 attack2 的本地 F24（整段 F44），引擎依赖使用源帧，显示保持整段帧。 |
| 回能过滤方向反了 | 别礼自身战技请求 16 点被禁止，队伍通用 6.5 点却流入 | `RefrainObtainUsp` 的指定 tag 是允许例外；保留通用资源 suppression 既有匹配语义，增加 `exceptTags`。从零能量施放自身战技回 16，汤汤战技不再给别礼通用回能。 |
| 持续动作目标绑定丢失 | 汤汤派生水龙卷的 12 跳打到自己，并向自己附着寒冷 | 编译和执行保留 Channeling 目标设置；首跳读取当次动作事务中新写入的 finder 结果，后续跳读取当前程序目标组。12 跳和寒冷均落到敌人。 |
| 能力实体结束后程序未停止 | 汤汤 Q 自然结束还继续执行提前结束路径，叠出 4 倍和 7 倍巨浪 | 实体结束取消其拥有的程序、间隔与监听，独立 Buff 和其他施法仍存活。自然 Q 为八次 0.4 倍加一次 4 倍；实际下落触发时变为两次 0.4 倍加一次 7 倍，只有一次跳转。 |
| Aura 和伤害前置事件缺失 | 友方下落监听挂到敌人，真实下落也无法触发 Q 提前结束 | 尊重明确阵营筛选与 Buff 来源实体；产生一次动作级 `OnBeforeDamageAction`，解析原始攻击规格和掩码，动态解析主控目标。 |
| 条件跳转被当成无条件 | 连携产生的两个涡流在 F26 出生当帧即销毁，后续战技水数永远为 0 | 在程序有效期内观察条件、状态改变后重新判断；F26 两水保留，F40 战技在 F51 分别唤醒对应实体，`water_cnt=2`。Prefab tag 以带公开数据证据的声明映射补齐。 |
| 单次伤害的 processor 被丢弃 | Q 提前结束后的水龙卷没有天赋增伤 | `DamageScaleProcessor` 进入同一个伤害解析器，攻击者与受击者分侧计算，保留 RD 来源输入。满技能、零潜的天赋为 +60%，不是 raw fallback 的 +30%；该实验每跳非暴击由 112.71775 改为 180.3484，RD 重构误差小于 1e-8。 |
| 派生技能身份继承错误 | 战技水龙卷沿用 Q 类型，触发与乘区可能按终结技判断 | 实际技能类型取派生程序自己的 SkillData，输入类型与根施法身份独立保存。 |
| 长轴结果静默截断 | `compactSquadHits` 只返回前 1200 条，汇总却含全部命中 | 返回全部实际命中。60 输入实验 1991 条命中完整保留；原截断遗漏约 39.57% 期望伤害。 |
| 浏览器结果多次重复完整明细 | 1991 命中的真实 HTTP 响应约 125.7 MB | 传输投影用 hitIndices 引用顶层唯一命中表，移除重复 lanes/resourcePools 别名；完整核心投影保留。响应约 46.6 MB，减少 62.9%，全部命中和资源点/事件保留；长轴完整日志的传输与解析成本仍存在。 |
| 固定事件上限拒绝受支持的长轴 | 约 23 次持续战技就会超过 10000 事件 | 应用预算为 10000 + 指令数×1024，仍受 80/320 输入上限约束；核心默认不变，同帧另保留 10000 事件防循环限制。 |
| 调试操作坐标持久化错误 | 画布组号误写成角色行，第二组局部节点误写成全局节点 | 调试命令沿用画布队列；持久化转换为角色行及全局节点，删除按实际存储行定位。Chrome 中汤汤第二组第 4 节点保存为角色行 1、全局节点 17，刷新仍一致，删除无残留。 |
| 调试命中关系能计算但不能保存 | 调试请求缺少 sourceHitId，排轴计算接受，但存档校验拒绝 | damage-hit 请求同时要求来源命中 ID 与偏移，命中 ID 支持预览实际使用的冒号格式；拒绝不完整输入。修正后的三动作轴通过真实保存与切换。 |
| 启动恢复可能先写入空队伍 | hydration ref 先变 true，同轮持久化 effect 仍持有初始空选择 | 改为随 React 状态提交的恢复标记。真实 StrictMode 隔离挂载原写序列为 `[[],[别礼,汤汤]]`，修后恢复两人且没有多余选择写入。已被写空的数据不自动用旧版本覆盖。 |
| 报表装备栏与实际计算不一致 | 未手动配置武器时显示“无”，引擎却使用默认武器 | 没有显式配置时展示实际结算 loadout，保留武器等级；别礼默认达尔霍夫7、汤汤默认佩科5均显示 Lv90，显式选择和等级继续优先，不回写队伍配置。 |

## 实验方法与边界

- 真实原始技能组合，改变初始主控、同帧换人前后顺序、命中后换人和普攻中插入战技；比较逐次命中、资源、状态和实体寿命。
- 普攻自然结束边界额外核对：A 结束 F131，战技 F130 仍可瞬时替代；F131/132/140 已离开普攻，占用恢复普通施放时长，原 A 标记 Completed。前端既有 group-seal 自动剪尾契约仍适用，natural duration 与 blocking duration 不应混淆。
- 汤汤技能等级/潜能 20 组单变量实验；自然结束与下落结束分支分别检查。相同输入重复运行三次、轴末追加 F450 普攻，不改变 Q 之前的命中。
- 共享双人七动作轴：重复运行、反转队员顺序和末尾追加动作，原 84 条历史命中一致。这些对照没有发现确定性回溯错误，不能据此推断所有轴都正确。
- 下落首击 F195/F196 可触发提前结束，F197 自然巨浪已发生。此处记录实际事件优先级边界，未擅自改写原始结束帧约定。
- Q 下落分支通过调度原始 `plunging_attack_end` 程序验证实际 Aura→事件→跳转→伤害链；这不等同于界面已有专用下落输入或完整下落操作流已验收。
- 两人连携待释放窗口沿用既有共享 180 tick（6 秒）约定，声明为公开数据推定；本轮验证触发、阈值与消费，未取得这两人的独立游戏窗口边界观测。
- 10/20/40/60 次间隔 360 帧的汤汤战技实验分别调度 4539/9081/17974/26957 个事件，尾部 pending 不超过 3；本机引擎耗时约 441/746/1425/2113 ms。这是合法复杂度随输入增长的证据，不能当成完整 UI 延迟保证；资源不足的输入仍明确拒绝。
- 异名能力实体销毁实验检查通用生命周期，避免仅让汤汤 ID 通过。
- 同时复查旧角色行为。新 Channeling 目标绑定曾暴露首跳读取旧 blackboard 的回归，修正后沃尔夫原 43 条 Calc 中断观测逐包通过，10 次燃烧尾伤保留。

## 开发者接口

`edit-timeline` 支持在当前 Chrome 的活动画布添加/移除具体技能按钮，以及显式设置对现有动作的开始、结束、命中释放关系，经过既有工作台命令队列；要求精确文档、角色、技能 ID。返回实际落点，错误、命令结果、后续重算和状态都可通过同一个 RIA Session 追溯。请求不支持脚本执行，详情见 [RIA quickstart](../guides/ria-quickstart.md)。
